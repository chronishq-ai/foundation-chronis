## 1. Generative Probabilistic Model

The Chronis Dual-Timescale Hidden Semi-Markov State-Space Model specifies the joint density of observed features $y_{1:T} \in \mathbb{R}^{T \times F}$, fast continuous latent states $m_{1:T} \in \mathbb{R}^{T \times L}$, and slow discrete regimes $p_{1:T} \in \{0, \dots, K-1\}$.

### 1.1 Fast Continuous Latent State Dynamics
Conditioned on regime $p_t = k$, the continuous state evolves as a first-order vector autoregressive process:
$$m_t = A_k m_{t-1} + b_k + w_t, \quad w_t \sim \mathcal{N}(0, Q_k)$$
where:
- $A_k \in \mathbb{R}^{L \times L}$ is the regime-dependent state transition matrix.
- $b_k \in \mathbb{R}^L$ is the continuous state drift vector.
- $Q_k \in \mathbb{R}^{L \times L}$ is the process noise covariance matrix (positive definite).

### 1.2 Emission Observation Model
Conditioned on regime $p_t = k$ and continuous state $m_t$, the observed behavioral feature vector $y_t \in \mathbb{R}^F$ is generated by:
$$y_t = C_k m_t + d_k + v_t, \quad v_t \sim \mathcal{N}(0, R_k)$$
where:
- $C_k \in \mathbb{R}^{F \times L}$ is the observation loading matrix mapping latent dynamics to behavioral indicators.
- $d_k \in \mathbb{R}^F$ is the regime-specific baseline offset.
- $R_k = \operatorname{diag}(\sigma_{k,1}^2, \dots, \sigma_{k,F}^2)$ is the diagonal observation noise covariance.

For partially missing observations (where mask $M_{t, f} = 1$), likelihood evaluation marginalizes out missing coordinates by selecting sub-matrix rows $C_{k, \text{obs}}$, $d_{k, \text{obs}}$, and $R_{k, \text{obs}}$.

### 1.3 Slow Discrete Semi-Markov Regime Dynamics
The sequence of macro-regimes follows a semi-Markov jump process:
1. Upon entering regime $k$, a dwell duration $d \in \{1, \dots, D_{\max}\}$ is drawn from a truncated log-normal distribution:
$$P(d \mid p_t = k) = \frac{\frac{1}{d \sigma_k \sqrt{2\pi}} \exp\left( -\frac{(\ln d - \mu_k)^2}{2\sigma_k^2} \right)}{\sum_{\tau=1}^{D_{\max}} \frac{1}{\tau \sigma_k \sqrt{2\pi}} \exp\left( -\frac{(\ln \tau - \mu_k)^2}{2\sigma_k^2} \right)}$$
2. After dwelling for duration $d$, a transition occurs to a new regime $j \ne k$ according to transition probability matrix $\Pi$:
$$\Pi_{k, j} = P(p_{t+d} = j \mid p_t = k), \quad \Pi_{k, k} = 0, \quad \sum_{j \ne k} \Pi_{k, j} = 1$$

## 2. Inference: Kim's Filter with GPB2 Collapse

Because exact inference over switching linear dynamical systems requires summing over $K^T$ mode histories, we utilize Kim's algorithm (Kim, 1994) with Gaussian Pseudo-Bayes 2 (GPB2) collapse.

### 2.1 State Representation
At time $t$, the belief state is parameterized by:
- Regime probabilities: $W_t^{(j)} = P(p_t = j \mid y_{1:t})$
- Conditional continuous moments: $\hat{m}_{t|t}^{(j)} = \mathbb{E}[m_t \mid p_t = j, y_{1:t}]$ and $P_{t|t}^{(j)} = \operatorname{Cov}(m_t \mid p_t = j, y_{1:t})$

### 2.2 Time Update & Measurement Update
For each candidate transition $(i \rightarrow j)$:
$$\hat{m}_{t|t-1}^{(i, j)} = A_j \hat{m}_{t-1|t-1}^{(i)} + b_j$$
$$P_{t|t-1}^{(i, j)} = A_j P_{t-1|t-1}^{(i)} A_j^T + Q_j$$
$$\tilde{y}_t^{(i, j)} = y_t - (C_j \hat{m}_{t|t-1}^{(i, j)} + d_j)$$
$$S_t^{(i, j)} = C_j P_{t|t-1}^{(i, j)} C_j^T + R_j$$
$$K_t^{(i, j)} = P_{t|t-1}^{(i, j)} C_j^T (S_t^{(i, j)})^{-1}$$
$$\hat{m}_{t|t}^{(i, j)} = \hat{m}_{t|t-1}^{(i, j)} + K_t^{(i, j)} \tilde{y}_t^{(i, j)}$$
$$P_{t|t}^{(i, j)} = (I - K_t^{(i, j)} C_j) P_{t|t-1}^{(i, j)}$$

### 2.3 GPB2 Moment Matching Collapse
The $K \times K$ branch estimates are collapsed into $K$ densities:
$$W_t^{(j)} = \sum_{i=1}^K W_{t-1}^{(i)} \Pi_{i, j} \mathcal{N}(\tilde{y}_t^{(i, j)}; 0, S_t^{(i, j)})$$
$$W_t^{(i \mid j)} = \frac{W_{t-1}^{(i)} \Pi_{i, j} \mathcal{N}(\tilde{y}_t^{(i, j)}; 0, S_t^{(i, j)})}{W_t^{(j)}}$$
$$\hat{m}_{t|t}^{(j)} = \sum_{i=1}^K W_t^{(i \mid j)} \hat{m}_{t|t}^{(i, j)}$$
$$P_{t|t}^{(j)} = \sum_{i=1}^K W_t^{(i \mid j)} \left[ P_{t|t}^{(i, j)} + (\hat{m}_{t|t}^{(i, j)} - \hat{m}_{t|t}^{(j)})(\hat{m}_{t|t}^{(i, j)} - \hat{m}_{t|t}^{(j)})^T \right]$$

## 3. Generalized Expectation-Maximization (GEM)

Parameter estimation optimizes the expected complete-data log-likelihood:
$$\mathcal{Q}(\theta, \theta^{(old)}) = \mathbb{E}_{m_{1:T}, p_{1:T} \mid y_{1:T}, \theta^{(old)}} \left[ \ln P(y_{1:T}, m_{1:T}, p_{1:T} \mid \theta) \right]$$

### 3.1 Monotonicity Guard & Backtracking Line Search
In the M-step, when non-linear optimization (such as numerical optimization of truncated log-normal duration parameters) proposes parameter update $\theta^{(new)}$:
1. Compute full model log-likelihood $\mathcal{L}(\theta^{(new)})$.
2. If $\mathcal{L}(\theta^{(new)}) < \mathcal{L}(\theta^{(old)}) - 10^{-6}$:
   - Backtrack step: $\theta^{(\alpha)} = (1-\alpha)\theta^{(old)} + \alpha \theta^{(new)}$ for $\alpha \in \{0.5, 0.25, 0.125, \dots\}$.
   - If no $\alpha \ge 2^{-10}$ improves likelihood, restore $\theta^{(old)}$, log `FitState.REJECTED_UPDATE`, and terminate.
